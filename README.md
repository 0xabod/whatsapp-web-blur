# WhatsApp Web Blur Pro 😎

Userscript adds privacy blur effect to WhatsApp Web.

## ✨ Features

* Blur chats, messages, images
* Hover to reveal
* Toggle ON/OFF
* Adjustable blur strength

## ⌨️ Shortcuts

* Ctrl + B → Toggle blur
* Ctrl + ↑ ↓ → Adjust blur

## 📦 Installation

1. Install Tampermonkey
2. Add script.user.js
3. Open WhatsApp Web

## ⚠️ Notes

* Works on web.whatsapp.com only
* May require updates if WhatsApp changes UI
